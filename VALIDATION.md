# Проверка проекта

12 октября 2026 года повторно выполнены проверки:

- Конфигурация Docker Compose — без ошибок.
- Синтаксис Bash-скриптов — без ошибок.
- Тесты проверки состояния DataNode — 7 из 7 прошли.

Полная проверка с запуском контейнеров выполняется отдельно командой:

```bash
bash tests/integration.sh
```

Она проверяет работу HDFS и сохранность файла после пересоздания контейнеров. На момент этой записи локальная сборка ещё скачивает Hadoop, поэтому её успешное завершение пока не подтверждено.

После публикации тот же тест автоматически запускается во вкладке Actions. Отчёты можно скачать из завершённого запуска.
